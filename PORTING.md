# Archery Revamped - Community Porting

Archery Revamped is open source under the MIT License.

Community ports are welcome!

## Officially Maintained Versions

The following Minecraft versions are planned to be officially maintained:

- 1.21.11
- 1.21.1
- 26.1+

Please avoid publishing separate ports for versions currently maintained by the official project.

## Unsupported Versions

Ports to other Minecraft versions are welcome.

Examples may include:

- 1.20.1
- Older Minecraft releases
- Future versions that the official project does not support
- Other compatible mod-loader versions

## Port Requirements

Under the MIT License, you must retain the original copyright and licence notice when redistributing substantial portions of Archery Revamped.

For community ports, I would also appreciate:

- Credit to **Archery Revamped / Lomin**
- A link to the original project
- Clearly stating that the port is unofficial
- Using a different project name where necessary to avoid confusion
- Reporting useful fixes upstream where possible

## Pull Requests

If your changes would also benefit the official version, feel free to submit a pull request instead of maintaining a separate fork.
